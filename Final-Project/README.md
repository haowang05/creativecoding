# Final-Project
### The Poetics of Error: User Perception and Artistic Potential of Demographic Misrecognition in AI Advertising

This archive contains the various files generated throughout the different stages of my Master’s project. The index is as follows:

1. [Development Log](https://git.arts.ac.uk/24010286/Final-Project/blob/main/Development%20Log.md) — Weekly development logs.

2. [identity-fragmentor](https://git.arts.ac.uk/24010286/Final-Project/tree/main/identity-fragmentor) — The final output produced for the Critical Design Practice component.

3. [ai-ad-archive](https://git.arts.ac.uk/24010286/Final-Project/tree/main/ai-ad-archive) — The local testing version of the code for the AI-generated advertising platform (the hosted version is published elsewhere; this folder contains only the local build).
4. [data](https://git.arts.ac.uk/24010286/Final-Project/tree/main/data) — Anonymized original datasets and multiple versions of the data analysis scripts.
5. [doc](https://git.arts.ac.uk/24010286/Final-Project/tree/main/doc) — Materials used in the final dissertation.


6. [td](https://git.arts.ac.uk/24010286/Final-Project/tree/main/td) — An experimental attempt to create an installation using TouchDesigner and LLMs, which was ultimately unsuccessful.


7. [Partial References](https://git.arts.ac.uk/24010286/Final-Project/tree/main/Partial%20References) — A selection of the academic references consulted during the project.
